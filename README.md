## Настройки Compose

В файле .env задаются:

APP_PORT — порт приложения внутри контейнера;

HOST_PORT — порт, доступный на компьютере;

GREETING — текст приветствия.

Для работы с Redis приложение использует STORAGE=redis и REDIS_URL=redis://redis:6379/0.

Приложение доступно по адресу http://localhost:8080.

В файле .env.example указан пример оформления .env
